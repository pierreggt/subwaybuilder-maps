# Muscat | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Muscat**, capital of Oman, from the international airport to Old Muscat, spanning the full coastal urban corridor.

### ✨ Features

- 🏙️ **82,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **592,000+ simulated commuters** based on NCSI (National Centre for Statistics and Information) wilayat-level population estimates, with jobs estimated from OpenStreetMap commercial density
- ✈️ **Muscat International Airport**
- 🎓 **Sultan Qaboos University**
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Muscat` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Oman** tab → **Muscat**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Mascate**, capitale d'Oman, de l'aéroport international à la vieille ville, couvrant tout le corridor urbain côtier.

### ✨ Contenu

- 🏙️ **Plus de 82 000 bâtiments** OpenStreetMap et Overture Maps (format binaire)
- 👥 **Plus de 592 000 actifs simulés**, basés sur les estimations de population par wilayat du NCSI (National Centre for Statistics and Information), avec emplois estimés depuis la densité commerciale OpenStreetMap
- ✈️ **Aéroport international de Mascate**
- 🎓 **Université Sultan Qaboos**
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Muscat` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Oman** → **Muscat**
