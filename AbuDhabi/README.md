# Abu Dhabi | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Abu Dhabi**, capital of the United Arab Emirates, from Zayed International Airport to Yas Island and Saadiyat Island.

### ✨ Features

- 🏙️ **111,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **1,170,000+ simulated commuters** based on 2024 SCAD (Statistics Centre Abu Dhabi) census population, with jobs estimated from OpenStreetMap commercial density
- ✈️ **Zayed International Airport**, with real 2024 passenger traffic data (origin-destination only, correspondance traffic excluded)
- 🎓 **Zayed University** Abu Dhabi campus
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `AbuDhabi` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **United Arab Emirates** tab → **Abu Dhabi**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte d'**Abu Dhabi**, capitale des Émirats arabes unis, de l'aéroport international Zayed à Yas Island et Saadiyat Island.

### ✨ Contenu

- 🏙️ **Plus de 111 000 bâtiments** OpenStreetMap et Overture Maps (format binaire)
- 👥 **Plus de 1 170 000 actifs simulés**, basés sur le recensement 2024 du SCAD (Statistics Centre Abu Dhabi), avec emplois estimés depuis la densité commerciale OpenStreetMap
- ✈️ **Aéroport international Zayed**, avec de vraies données de trafic passagers 2024 (uniquement origine-destination, correspondances exclues)
- 🎓 Campus Abu Dhabi de la **Zayed University**
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `AbuDhabi` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **United Arab Emirates** → **Abu Dhabi**
