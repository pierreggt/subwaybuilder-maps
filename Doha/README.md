# Doha | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Doha**, Qatar's capital, from Hamad International Airport to Lusail, spanning the full Doha Metro network (Red, Green and Gold lines).

### ✨ Features

- 🏙️ **240,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **1,071,000+ simulated commuters** based on the 2020 Qatar census (Planning and Statistics Authority) population by municipality, with jobs estimated from OpenStreetMap commercial density
- ✈️ **Hamad International Airport**, with real 2025 record passenger traffic data
- 🎓 **Qatar University** and **Education City** (Qatar Foundation's partner university campuses)
- 🚇 The full **Doha Metro** network footprint (Red/Green/Gold lines) is covered, from Al Wakra to Lusail and Al Riffa to the airport
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Doha` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Qatar** tab → **Doha**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Doha**, capitale du Qatar, de l'aéroport international Hamad à Lusail, couvrant tout le réseau du Doha Metro (lignes rouge, verte et or).

### ✨ Contenu

- 🏙️ **Plus de 240 000 bâtiments** OpenStreetMap et Overture Maps (format binaire)
- 👥 **Plus de 1 071 000 actifs simulés**, basés sur la population du recensement qatari 2020 (Planning and Statistics Authority) par municipalité, avec emplois estimés depuis la densité commerciale OpenStreetMap
- ✈️ **Aéroport international Hamad**, avec de vraies données de trafic passagers 2025 (record)
- 🎓 **Université du Qatar** et **Education City** (campus universitaires partenaires de la Qatar Foundation)
- 🚇 L'empreinte complète du réseau **Doha Metro** (lignes rouge/verte/or) est couverte, d'Al Wakra à Lusail et d'Al Riffa à l'aéroport
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Doha` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Qatar** → **Doha**

### 🙏 Crédits

Données © contributeurs OpenStreetMap (ODbL), Overture Maps Foundation, Qatar Planning and Statistics Authority (PSA/NPC), recensement 2020.
