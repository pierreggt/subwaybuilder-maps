# Kuwait City | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Kuwait City**, capital of Kuwait, from the international airport to Jahra and Fahaheel, covering all six governorates of Greater Kuwait.

### ✨ Features

- 🏙️ **167,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **1,913,000+ simulated commuters** based on the 2021 census population by governorate, with jobs estimated from OpenStreetMap commercial density
- ✈️ **Kuwait International Airport**, with real 2024 passenger traffic data
- 🎓 **Kuwait University** (Sabah Al-Salem University City campus)
- 🛍️ **The Avenues Mall**, one of the largest shopping centers in the Middle East
- 🗼 **Kuwait Towers**
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `KuwaitCity` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Kuwait** tab → **Kuwait City**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Koweït City**, capitale du Koweït, de l'aéroport international à Jahra et Fahaheel, couvrant les six gouvernorats du Grand Koweït.

### ✨ Contenu

- 🏙️ **Plus de 167 000 bâtiments** OpenStreetMap et Overture Maps (format binaire)
- 👥 **Plus de 1 913 000 actifs simulés**, basés sur la population du recensement 2021 par gouvernorat, avec emplois estimés depuis la densité commerciale OpenStreetMap
- ✈️ **Aéroport international du Koweït**, avec de vraies données de trafic passagers 2024
- 🎓 **Université du Koweït** (campus Sabah Al-Salem University City)
- 🛍️ **The Avenues Mall**, un des plus grands centres commerciaux du Moyen-Orient
- 🗼 **Kuwait Towers**
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `KuwaitCity` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Kuwait** → **Kuwait City**
