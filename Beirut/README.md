# Beirut | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Beirut**, capital of Lebanon, from Rafic Hariri International Airport to Jounieh, spanning the Beirut and Mount Lebanon urban corridor.

### ✨ Features

- 🏙️ **119,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **882,000+ simulated commuters** based on the best available district-level population estimates (Central Administration of Statistics), with jobs estimated from OpenStreetMap commercial density
- ✈️ **Beirut–Rafic Hariri International Airport**, with real 2023 passenger traffic data
- 🎓 **American University of Beirut** (AUB)
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Beirut` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Lebanon** tab → **Beirut**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte du **Grand Beyrouth**, capitale du Liban, de l'aéroport international Rafic Hariri à Jounieh, couvrant le corridor urbain Beyrouth/Mont-Liban.

### ✨ Contenu

- 🏙️ **Plus de 119 000 bâtiments** OpenStreetMap et Overture Maps (format binaire)
- 👥 **Plus de 882 000 actifs simulés**, basés sur les meilleures estimations de population disponibles par district (Central Administration of Statistics), avec emplois estimés depuis la densité commerciale OpenStreetMap
- ✈️ **Aéroport international Rafic Hariri**, avec de vraies données de trafic passagers 2023
- 🎓 **American University of Beirut** (AUB)
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Beirut` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Lebanon** → **Beirut**
