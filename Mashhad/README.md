# Mashhad | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Mashhad**, Iran's second-largest city and one of the largest Shia pilgrimage destinations in the world, centered on the Imam Reza shrine.

### ✨ Features

- 🏙️ **336,000+ buildings** from OpenStreetMap (binary format)
- 👥 **1,579,000+ simulated commuters** based on the 2016 Iranian census population by district, with jobs estimated from OpenStreetMap commercial density
- 🕌 **Imam Reza Shrine**, one of the largest mosque/shrine complexes in the world
- 🎓 **Realistic traffic generators**: Ferdowsi University of Mashhad, Mashhad University of Medical Sciences
- ✈️ **Mashhad International Airport**, with a direct metro connection to the terminal
- 🚆 **Mashhad Railway Station**
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Mashhad` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Iran** tab → **Mashhad**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Mashhad**, deuxième plus grande ville d'Iran et l'une des plus grandes destinations de pèlerinage chiite au monde, centrée sur le sanctuaire de l'Imam Reza.

### ✨ Contenu

- 🏙️ **Plus de 336 000 bâtiments** OpenStreetMap (format binaire)
- 👥 **Plus de 1 579 000 actifs simulés**, basés sur le recensement iranien de 2016 par district, avec emplois estimés depuis la densité commerciale OpenStreetMap
- 🕌 **Sanctuaire de l'Imam Reza**, l'un des plus grands complexes de mosquée/sanctuaire au monde
- 🎓 **Pôles de trafic** : Université Ferdowsi de Mashhad, Université des sciences médicales de Mashhad
- ✈️ **Aéroport international de Mashhad**, avec connexion metro directe au terminal
- 🚆 **Gare de Mashhad**
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Mashhad` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Iran** → **Mashhad**
