# Alexandria | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Alexandria**, Egypt's second largest city, from Alexandria International Airport to Abu Qir, along the full Mediterranean coastal corridor.

### ✨ Features

- 🏙️ **382,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **2,393,000+ simulated commuters** based on the CAPMAS 2024 population estimate, with jobs estimated from OpenStreetMap commercial density
- ✈️ **Alexandria International Airport** (formerly Borg El Arab)
- 🎓 **Alexandria University**
- 📚 **Bibliotheca Alexandrina**
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Alexandria` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Egypt** tab → **Alexandria**

⚠️ Keep the terminal window open while playing.
