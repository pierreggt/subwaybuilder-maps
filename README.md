# Subway Builder Maps — pierreggt collection

A shared repository of community-created [Subway Builder](https://store.steampowered.com/app/2716540/Subway_Builder/) maps, built with [depot](https://github.com/Subway-Builder-Modded/depot).

Each map lives in its own top-level folder and is also published as a versioned [GitHub Release](../../releases), one release per map (tag format `<code>-vX.Y.Z`), with the release asset being the flat data zip consumed by the [Subway-Builder-Modded registry](https://github.com/Subway-Builder-Modded/registry).
