# Baghdad | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Baghdad**, Iraq's capital, covering the city core from Baghdad International Airport to Sadr City and Kadhimiya.

### ✨ Features

- 🏙️ **960,000+ buildings** from OpenStreetMap (binary format)
- 👥 **3,161,500+ simulated commuters** based on the November 2024 Iraqi census population data by district, with jobs estimated from OpenStreetMap commercial density
- 🎓 **Realistic traffic generators**: University of Baghdad, Al-Nahrain University, Al-Mustansiriya University
- ✈️ **Baghdad International Airport**, with real passenger traffic data (connecting passengers excluded)
- 🕌 **Al-Kadhimiya Shrine**, a major Shia pilgrimage site
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Baghdad` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Iraq** tab → **Baghdad**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Bagdad**, capitale de l'Irak, couvrant le cœur de la ville de l'aéroport international à la ville de Sadr et Kadhimiya.

### ✨ Contenu

- 🏙️ **Plus de 960 000 bâtiments** OpenStreetMap (format binaire)
- 👥 **Plus de 3 161 500 actifs simulés**, basés sur le recensement irakien de novembre 2024 par district, avec emplois estimés depuis la densité commerciale OpenStreetMap
- 🎓 **Pôles de trafic** : Université de Bagdad, Université Al-Nahrain, Université Al-Mustansiriya
- ✈️ **Aéroport international de Bagdad**, avec de vraies données de trafic passagers (passagers en correspondance exclus)
- 🕌 **Sanctuaire de Kadhimiya**, site majeur de pèlerinage chiite
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Baghdad` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Iraq** → **Baghdad**

### 🙏 Crédits

Données © contributeurs OpenStreetMap (ODbL), Organisation centrale de statistiques d'Irak (COSIT), recensement 2024.
