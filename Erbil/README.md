# Erbil | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Erbil (Hewler)**, capital of the Kurdistan Region of Iraq, covering the city core from Erbil International Airport to the historic Citadel.

### ✨ Features

- 🏙️ **250,000+ buildings** from OpenStreetMap (binary format)
- 👥 **389,800+ simulated commuters** based on the November 2024 Iraqi census population data by district, with jobs estimated from OpenStreetMap commercial density
- 🎓 **Realistic traffic generators**: Salahaddin University-Erbil, Hawler Medical University, University of Kurdistan Hewler (UKH)
- ✈️ **Erbil International Airport**, with real 2024 passenger traffic data
- 🏛️ **Erbil Citadel**, a UNESCO World Heritage site at the heart of the city
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Erbil` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Iraq** tab → **Erbil**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte d'**Erbil (Hewlêr)**, capitale de la région du Kurdistan irakien, couvrant le cœur de la ville de l'aéroport international à la Citadelle historique.

### ✨ Contenu

- 🏙️ **Plus de 250 000 bâtiments** OpenStreetMap (format binaire)
- 👥 **Plus de 389 800 actifs simulés**, basés sur le recensement irakien de novembre 2024 par district, avec emplois estimés depuis la densité commerciale OpenStreetMap
- 🎓 **Pôles de trafic** : Université Salahaddin-Erbil, Université médicale de Hawler, Université du Kurdistan-Hewlêr (UKH)
- ✈️ **Aéroport international d'Erbil**, avec de vraies données de trafic passagers 2024
- 🏛️ **Citadelle d'Erbil**, site classé au patrimoine mondial de l'UNESCO au cœur de la ville
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Erbil` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Iraq** → **Erbil**

### 🙏 Crédits
