# Aleppo | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Aleppo**, Syria's second-largest city, from the historic Old City to Aleppo International Airport.

### ✨ Features

- 🏙️ Buildings from OpenStreetMap (binary format)
- 👥 **979,400+ simulated commuters** based on the 2004 census by district (latest complete census available — Aleppo was the most devastated city of the Syrian civil war, see caveats below), with jobs estimated from OpenStreetMap commercial density
- ✈️ **Aleppo International Airport**, with real 2025 passenger traffic data reflecting the post-war recovery
- 🎓 **University of Aleppo**, Syria's second-largest public university
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Aleppo` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Syria** tab → **Aleppo**

⚠️ Keep the terminal window open while playing.

### 🙏 Credits

Data © OpenStreetMap contributors (ODbL). Population estimates: Syrian Central Bureau of Statistics (2004 census, latest available for this city).

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte d'**Alep**, deuxième plus grande ville de Syrie, de la vieille ville historique à l'aéroport international d'Alep.

### ✨ Contenu

- 🏙️ Bâtiments OpenStreetMap (format binaire)
- 👥 **Plus de 979 400 actifs simulés**, basés sur le recensement 2004 par district (dernier recensement complet disponible — Alep a été la ville la plus dévastée de la guerre civile syrienne, voir réserves ci-dessous), avec emplois estimés depuis la densité commerciale OpenStreetMap
- ✈️ **Aéroport international d'Alep**, avec de vraies données de trafic passagers 2025 reflétant la reprise post-guerre
- 🎓 **Université d'Alep**, deuxième plus grande université publique de Syrie
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Aleppo` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Syria** → **Aleppo**

### 🙏 Crédits

Données © contributeurs OpenStreetMap (ODbL). Estimations de population : Bureau central de statistiques syrien (recensement 2004, le plus récent disponible pour cette ville).
