# Damascus | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Damascus**, Syria's capital, from the historic Old City to Damascus International Airport.

### ✨ Features

- 🏙️ Buildings from OpenStreetMap (binary format)
- 👥 **1,685,050+ simulated commuters** based on the best available population estimates by district (post-2004 census updates where documented: IOM/WHO 2025 for Damascus city, OCHA-sourced 2023 figures for Al-Tall and Saidnaya), with jobs estimated from OpenStreetMap commercial density
- ✈️ **Damascus International Airport**, with real 2025 passenger traffic data (post-transition recovery)
- 🎓 **Damascus University**, Syria's oldest and largest public university
- 🏭 **Adra Industrial City**, Syria's largest industrial zone
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Damascus` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Syria** tab → **Damascus**

⚠️ Keep the terminal window open while playing.

Data © OpenStreetMap contributors (ODbL). Population estimates: Syrian Central Bureau of Statistics (2004 census, latest available), IOM Displacement Tracking Matrix, WHO, OCHA.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Damas**, capitale de la Syrie, de la vieille ville historique à l'aéroport international de Damas.

### ✨ Contenu

- 🏙️ Bâtiments OpenStreetMap (format binaire)
- 👥 **Plus de 1 685 050 actifs simulés**, basés sur les meilleures estimations de population disponibles par district (mises à jour post-recensement 2004 quand documentées : IOM/OMS 2025 pour la ville de Damas, chiffres OCHA 2023 pour Al-Tall et Saidnaya), avec emplois estimés depuis la densité commerciale OpenStreetMap
- ✈️ **Aéroport international de Damas**, avec de vraies données de trafic passagers 2025 (reprise post-transition)
- 🎓 **Université de Damas**, la plus ancienne et plus grande université publique de Syrie
- 🏭 **Cité industrielle d'Adra**, plus grande zone industrielle de Syrie
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Damascus` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Syria** → **Damascus**

### 🙏 Crédits

Données © contributeurs OpenStreetMap (ODbL). Estimations de population : Bureau central de statistiques syrien (recensement 2004, le plus récent disponible), IOM Displacement Tracking Matrix, OMS, OCHA.
