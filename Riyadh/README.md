# Riyadh | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Riyadh**, Saudi Arabia's capital, featuring the newly-completed 6-line Riyadh Metro network (fully opened January 2025), from King Khalid International Airport to the historic Diriyah district.

### ✨ Features

- 🏙️ **559,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **3,552,000+ simulated commuters** based on the 2022 Saudi census (GASTAT) population, with jobs estimated from OpenStreetMap commercial density
- 🎓 **Realistic traffic generators**: King Saud University, Imam Mohammad Ibn Saud Islamic University, Princess Nourah bint Abdulrahman University
- 🏦 **King Abdullah Financial District (KAFD)**
- ✈️ **King Khalid International Airport**, with real 2025 passenger traffic data
- 🏛️ **Diriyah / At-Turaif**, UNESCO World Heritage site
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Riyadh` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Saudi Arabia** tab → **Riyadh**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Riyad**, capitale de l'Arabie saoudite, avec le tout nouveau réseau de métro à 6 lignes (entièrement ouvert en janvier 2025), de l'aéroport international King Khalid au quartier historique de Diriyah.

### ✨ Contenu

- 🏙️ **Plus de 559 000 bâtiments** OpenStreetMap et Overture Maps (format binaire)
- 👥 **Plus de 3 552 000 actifs simulés**, basés sur le recensement saoudien 2022 (GASTAT), avec emplois estimés depuis la densité commerciale OpenStreetMap
- 🎓 **Pôles de trafic** : Université du Roi Saoud, Université islamique Imam Mohammad Ibn Saud, Université Princesse Nourah bint Abdulrahman
- 🏦 **Quartier financier King Abdullah (KAFD)**
- ✈️ **Aéroport international King Khalid**, avec de vraies données de trafic passagers 2025
- 🏛️ **Diriyah / At-Turaif**, site classé au patrimoine mondial de l'UNESCO
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Riyadh` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Saudi Arabia** → **Riyadh**
