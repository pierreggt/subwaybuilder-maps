# Shiraz | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of **Shiraz**, capital of Fars province and one of Iran's major cultural and tourist cities, famed for its gardens, poets, and historic sites.

### ✨ Features

- 🏙️ **169,000+ buildings** from OpenStreetMap and Overture Maps (binary format)
- 👥 **819,000+ simulated commuters** based on the 2016 Iranian census population by district, with jobs estimated from OpenStreetMap commercial density
- 🎓 **Realistic traffic generators**: Shiraz University, Shiraz University of Medical Sciences
- ✈️ **Shiraz Shahid Dastgheib International Airport**
- 🚆 **Shiraz Railway Station**
- 🚗 **Simulated traffic congestion** on longer commutes
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Shiraz` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **Iran** tab → **Shiraz**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant une carte de **Chiraz**, capitale de la province du Fars et l'une des grandes villes culturelles et touristiques d'Iran, réputée pour ses jardins, ses poètes et ses sites historiques.

### ✨ Contenu

- 🏙️ **Plus de 169 000 bâtiments** OpenStreetMap et Overture Maps (format binaire)
- 👥 **Plus de 819 000 actifs simulés**, basés sur le recensement iranien de 2016 par district, avec emplois estimés depuis la densité commerciale OpenStreetMap
- 🎓 **Pôles de trafic** : Université de Chiraz, Université des sciences médicales de Chiraz
- ✈️ **Aéroport international Shahid Dastgheib de Chiraz**
- 🚆 **Gare de Chiraz**
- 🚗 **Trafic routier simulé** sur les longs trajets
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Shiraz` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **Iran** → **Shiraz**
